# 🌹 Whispers of the Heart

An interactive poetry garden where emotions become poems.

## ✨ Features

- 🌹 30 original poems
- 🔍 Search poems
- 📖 Interactive poem popups
- ⬅️ Previous / Next navigation
- 🌸 Falling petals
- ✨ Animated background
- 🖱️ Custom cursor effects
- 💫 Click animations
- 📱 Responsive design

## 🛠️ Technologies

- CSS
- JavaScript
